Sobre o Projeto

PartNest B existe para oferecer um controle local, simples e legível de assinaturas compartilhadas.

A proposta do projeto é permitir que você organize pessoas, serviços, saldos e cronogramas sem depender de uma plataforma remota para algo que muitas vezes será consultado poucas vezes ao ano.

Motivação

A ideia do projeto veio da necessidade de ter um controle fácil de administrar sem precisar entregar todos os dados para um aplicativo que você talvez use poucas vezes no ano e que ainda pode expor essas informações em algum incidente.

Modelo Local

Neste formato em HTML, os dados ficam com você. Não existe troca com nuvem para o funcionamento principal da aplicação, e o armazenamento acontece localmente no navegador e em exportações JSON feitas por você.

Trade-off

A contrapartida é que a administração dos dados pode exigir mais cuidado, já que não há uma infraestrutura remota gerenciando contas, sincronização ou recuperação automática de backup.

Nome do Projeto

O projeto anteriormente utilizava o nome Splitdz B. O nome foi alterado para PartNest B porque a nomenclatura anterior já era usada em outro contexto comercial.

Uso Não Comercial

PartNest B é usado aqui apenas como identidade alusiva do projeto, sem finalidade comercial.

Entenda os Cálculos

Custo Mensal

É a média de gastos considerando o ciclo de cada serviço. Assinaturas Mensais somam o valor integral. Assinaturas Anuais são divididas por 12.

Projeção Anual

Estimativa do custo total para os próximos 12 meses, baseada na média mensal atual multiplicada por 12.

Balanço Individual

  • Receber: Valor que os outros membros devem pagar a você (você é o gestor/pagador da conta).
  • Pagar: Valor que você deve ao gestor de uma conta que você participa.
  • Saldo Líquido: É a diferença entre o que você tem a receber e o que tem a pagar no período.

Cota por Pessoa

Calculada dividindo o valor total da assinatura pelo número de participantes selecionados na divisão (incluindo o pagador).

Pendências

Contagem de divisões onde o status de pagamento individual ainda está como Pendente. O gestor da conta é marcado como Pago automaticamente.
